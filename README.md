## 📖 Abstract

Bridging emotions and visual content for emotion-driven image editing holds great potential in creative industries, yet precise manipulation remains challenging due to the abstract nature of emotions. We propose **Moodifier**, an integrated approach consisting of three complementary components:

1.  **MoodArchive**: A dataset of over **8 million images** with hierarchical emotional annotations generated by LLaVA and validated by humans.
2.  **MoodifyCLIP**: A vision-language model fine-tuned on MoodArchive to translate abstract emotions into specific visual attributes using Optimal Transport and Fine-grained losses.
3.  **Moodifier Editor**: A training-free editing pipeline leveraging MoodifyCLIP and Multimodal LLMs (MLLMs) to enable precise emotional transformations while preserving content integrity.

## ✨ Key Features

* **Training-Free Editing**: Leverages pre-trained diffusion models with MLLM guidance.
* **Hierarchical Understanding**: Decomposes abstract emotions (e.g., "Excitement") into concrete visual attributes (e.g., "vibrant patterns", "bright smile").
* **Structure Preservation**: Uses attention control and Grounded-SAM to modify only relevant regions.
* **Versatile**: Works across diverse domains including facial expressions, fashion design, jewelry, and home décor.

## 🚀 Usage
Quick Start (Demo)
To run the emotion editing demo using the provided script:

```python
python run_editing_demoapp.py \
  --image_path "examples/source_image.jpg" \
  --target_emotion "joyful" \
  --output_path "outputs/"
```

Pipeline Overview
- Inversion: The source image is inverted to obtain the latent noise z_T.

- MLLM Guidance: LLaVA-NeXT generates a detailed emotional prompt and identifies ROI (Regions of Interest).

- Attention Control: Using ptp_utils.py, we blend the self-attention maps of the source with the target to preserve structure.

- MoodifyCLIP Guidance: The diffusion process is guided by our fine-tuned MoodifyCLIP model to ensure the visual attributes match the target emotion.
